# Security Policy

## Supported versions

Security fixes are provided for the latest release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
[git@kyaulabs.com](mailto:git@kyaulabs.com) with a description, reproduction
steps, affected versions, and any suggested remediation.

You should receive an acknowledgement within 48 hours. Please allow time for a
fix and coordinated disclosure before publishing details.
